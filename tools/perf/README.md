# tools/perf: performance measurements (not tests; `tools/verify.sh` does not run them)

`perf_*.js` run against this checkout (`NODE_PATH=$(npm root -g) node tools/perf/perf_steps.js A m2 real_balanced 1`): wheel steps with per-step render ms / walls / native call counts, focus and resize behaviour, pan cache at devicePixelRatio 1 / 1.25 / 2, pan-cache and zoom-step timings. `probe_*.js`, `mkprobe.sh`, `probe_f0.patch` and `probe_gate_q.patch` (PR F1 gate: tile identity, `probe_tile_identity.js`; `perf_raster_translation.js` is a self-contained browser test of the translation dependence of the canvas rasteriser) need a throw-away probe worktree (`mkprobe.sh <commit> <dir>`, then apply the patch; paths in `probe_lib.js` point to `/tmp/claude-0/wt_f0`): section timers, wall-height histogram, CPU profile and the look mocks of PR F2 (wall LOD, slab stamp); the patch is never part of `src/`. Absolute ms are those of the machine that ran them (headless software render).

PR G (E2 removed): `perf_pan_cache.js` was deleted with the pan cache. `perf_zoom_steps.js`, `perf_tile_fixed_cost.js`, `probe_tile_identity.js` and the pan-cache part of `perf_stripes.js` call `E.renderLayer`, `E.blitPan`, `#t-panCache` or `__evo.panLayerInfo`, which exist only up to commit 88a621d (PR #52); run them on a checkout of that commit. `e.panRest()` became `e.redraw()` (a plain `invalidate(false)`).
